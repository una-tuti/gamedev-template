# 要件定義書 
## どんなゲームか
- ゴールを目指すゲーム
## 勝ち条件/負け条件
- ゴールに触れたら勝ち
- HPが0以下になったら負け
- HPは敵に当たると10ダメージ、落下すると20ダメージ
## 作らないもの
- 背景や地面の色は白、輪郭だけ黒
- 音楽や効果音、エフェクトは作らない
- セーブ、ロードは作らない
- 取ることでジャンプ、ダッシュの待ち時間が0になるものも追加したいが今回は作らない
## これが出来たら完成
- 地形を作る　〇
- 地形に乗れるようにする　〇
- 壁に当たると止まるようにする　〇
- 敵に当たるとダメージを10食らう
- 左右キーで移動する　〇
- zボタンで4マスジャンプする　〇
- xボタンで6マス向いている方向にダッシュする　〇
- ジャンプ、ダッシュは2秒おきに使える　〇
- 空中にいるとき落ちるようにする　〇
- 落下したときは20ダメージ食らい落下する前最後に立っていた足場に戻る　〇
- ゴールを作る
- ゴールまでの道筋を作る、自分で(出来るだけ容易に)作成できるようにする
