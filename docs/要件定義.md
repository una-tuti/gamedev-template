# 要件定義書 
## どんなゲームか
- ゴールを目指すゲーム
## 勝ち条件/負け条件
- ゴールに触れたら勝ち
- HPが0以下になったら負け
- HPは敵に当たると10ダメージ、落下すると20ダメージ
## 作らないもの
- 背景や地面の色は白、輪郭だけ黒
- 音楽や効果音、エフェクトは作らない
- セーブ、ロードは作らない
- 取ることでジャンプ、ダッシュの待ち時間が0になるものも追加したいが今回は作らない
## これが出来たら完成
- 地形を作る
- 地形に乗れるようにする
- 壁に当たると止まるようにする
- 敵に当たるとダメージを10食らう
- 左右キーで移動する
- zボタンで4マスジャンプする
- xボタンで4マス向いている方向にダッシュする
- ジャンプ、ダッシュは2秒おきに使える
- 空中にいるとき落ちるようにする
- 落下したときは20ダメージ食らい落下する前最後に立っていた足場に戻る
